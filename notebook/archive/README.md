# Архив экспериментов из чатов

Записи ранних экспериментов, которые проводились в чатах с ИИ-ассистентами до того, как появились протоколы и отчёты. Это не опыты по методике лаборатории: условия не зафиксированы, цифры не проверены. Ценность записей — в идеях и наблюдениях, из которых потом вырастают гипотезы.

Одна запись — один файл `ГГГГ-ММ-ДД-короткое-название.md` по шаблону [`templates/chat-archive.md`](../../templates/chat-archive.md).
