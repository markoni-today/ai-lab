# Правила для агентов

Правила обязательны для любого ИИ-агента, который работает в этом репозитории.

## Git: одна ветка

- Работай только в ветке `ai-lab`. Перед началом: `git checkout ai-lab && git pull origin ai-lab`.
- Новые ветки не создавай. Это правило отменяет стандартное поведение агента «новая ветка на каждую задачу».
- Коммить и пушь в `ai-lab`: `git push origin ai-lab`.
- Перед коммитом запусти `scripts/check-branch.sh`. Если он вернул ошибку, остановись и сообщи автору.
- Pull request не открывай, если автор явно не попросил.
- Направления и опыты — это папки в `directions/`, а не ветки.

## Как оформлять

- Язык — русский. Шаблоны лежат в `templates/`, не придумывай свой формат.
- Каждый факт — с источником и датой. Нет источника — пометка «не подтверждено».
- Плохие цифры не прячем.
- Ключи, токены и личные данные в репозиторий не кладём: он публичный.
- Опыты не запускаем и ничего не публикуем без явного разрешения автора.
