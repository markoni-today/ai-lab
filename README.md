# AI Lab

Личная ИИ-лаборатория: учиться на экспериментах, получать честные цифры, делиться тем, что повторяемо. Не стартап и не корпоративный R&D — indie-лаба с двумя связанными треками.

## Для кого

В первую очередь — для автора (рост, ясность, портфолио). Во вторую — для коллег и читателей, которым полезны протоколы и цифры, а не лозунги.

## Два трека

### 1. Поиск (сейчас в фокусе)

Разбираем, от чего зависит качество ответов с поиском у языковых моделей:

- сама модель;
- обвязка вокруг модели (как ходим в веб, как цитируем, как режем мусор);
- навыки и инструкции агента.

Цель не «обойти Perplexity во всём», а понять границы и, где узко, превзойти. Важно качество под рабочие задачи (OSINT, факты для продукта), а не только быстрый ответ в чате.

### 2. Маркетинг B2B SaaS (позже)

Сделать продуктовый маркетинг воспроизводимым — как бенч или деплой в коде: что делаем → для кого → зачем → какие метрики → как повторить → когда приём работает или не работает.

Рой агентов исполняет протокол; человек утверждает необратимые шаги. Трек поиска — инфраструктура для этого роя (нормальный поиск фактов без выдумок).

## Что считаем успехом

- Есть понятная миссия и правила работы.
- Каждый опыт: гипотеза, метрики, артефакты, вывод — можно повторить.
- Публикуем честно: и удачи, и промахи.
- Коллеги могут взять протокол и прогнать у себя.

## Чего лаба не делает

- Не гоняет опыты «потому что интересно», без утверждённой гипотезы.
- Не выдаёт маркетинг-советы без условий применимости.
- Не прячет плохие цифры.

## Статус

Фундамент в работе. Пилотные прогоны не канон процесса, пока не утверждены правила запуска опытов.
